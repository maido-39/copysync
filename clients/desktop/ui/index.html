보내기

아무 앱에서나 텍스트·이미지를 복사하면 자동으로 동기화됩니다. 큰 파일은 받는 쪽이 요청할 때 전송됩니다.

전송 대상

기본은 전체 브로드캐스트입니다. 특정 기기를 선택하면 그 기기에만 전송합니다.

화면 / 테마

드래그해서 위치 조정

배경 이미지는 이 PC에만 저장됩니다. 박스 투명도를 낮추면 뒤 배경이 비쳐 보입니다.

동기화 · 보안

비밀번호·카드·키·OTP로 추정되는 클립은 다른 기기로 보내지 않습니다.

받은 클립을 Windows 클립보드 기록(Win+V)·클라우드 동기화에서 제외합니다.

받은 텍스트를 일정 시간 뒤 클립보드에서 지웁니다 (비밀번호 흔적 최소화).

창을 닫으면 트레이로 최소화되고 동기화는 계속됩니다.

단축키

전역 단축키입니다. "변경"을 누른 뒤 원하는 조합(예: Ctrl+Shift+V)을 누르세요 — 어디서든 최근 복사 기록 오버레이를 띄웁니다. Esc로 취소, "해제"로 끄기.

기기 페어링 / 재페어링

서버 관리자 화면에서 OTP를 만들어 입력하세요. 핀을 비우면 최초 접속 시 자동 신뢰합니다.
